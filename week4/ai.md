# Overview of LLMs and prompts I used
The main LLM I used for this deliverable was ChatGPT (the free version). The main conversation I used can be viewed here: . I used it largely for generating the code for algorithms that I explained to it, as well as the setup of my test file.

I started by providing it a description of the deliverable to give it context, as well as the example AI prompt 1 from Piazza.

**Code Generation**: By providing it with descriptions of the algorithms from the class slides and my own understanding, as well as file stubs with comments describing the steps of the algorithms, I got it to generate initial drafts of each of the alignment algorithms. Aside from minor tweaks, the methods it generated all worked very well. 

**Test File Setup**: I got it to generate a fasta file parser and a main function that would enumerate test pairs to pass into a `run_tests` function.

**Automation debugging**: The `evaluate.sh` I drafted was pretty simple, but ended up producing no output initially, so I used AI to debug it.
